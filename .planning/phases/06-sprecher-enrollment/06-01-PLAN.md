<objective>
Backend-Fundament für Sprecher-Enrollment schaffen: `ParakeetClient.enrollSpeaker(audioURL:name:)`
extrahiert ein 256-dim Speaker-Embedding via FluidAudio und persistiert ein permanentes Profil.
`SpeakerProfileViewModel.addEnrolledSpeaker` macht das neue Profil sichtbar im UI-State.
`ModeProcessor.parakeetClient` wird `internal` für DI in Wave 3.

Purpose: SPK-08 verlangt einen Enrollment-Pfad, der lokal auf dem Gerät ein permanentes Sprecher-Profil aus einer 15s-Aufnahme anlegt. Wave 1 stellt die testbaren API-Bausteine (Backend + Store-VM) bereit, bevor Wave 2 das ViewModel und Wave 3 die UI darauf setzen.

Output: Erweiterter ParakeetClient + EnrollmentError + erweiterter SpeakerProfileViewModel + sichtbarkeitsgeöffneter ModeProcessor + Unit-Tests, die alle Fehler- und Erfolgs-Pfade abdecken.
</objective>
