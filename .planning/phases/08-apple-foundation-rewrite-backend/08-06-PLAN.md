<objective>
CR-01 Fix: NotificationCenter-Observer-Leak in AppDelegate beheben.

Purpose: Der `addObserver(forName:)`-Block-basierte Observer aus Plan 08-04 (AppDelegate.swift:124-137) speichert das Rückgabe-Token nicht und ruft kein removeObserver. Im XCTest-Hosted-Run akkumulieren stale Observer; potenzieller Use-After-Free + Multi-Fire mit stale State. Zusätzlich: `[weak settingsStore]`-Capture und `_ = settingsStore` sind toter Code (Closure nutzt `self?.settingsStore`).

Output: AppDelegate hat Token-Property, applicationWillTerminate räumt sauber auf, toter Code ist entfernt — AC-AVAIL-2-Verhalten bleibt erhalten.

<interfaces>
Aktueller leaky Code (AppDelegate.swift:124-137):

```swift
NotificationCenter.default.addObserver(
    forName: NSApplication.didBecomeActiveNotification,
    object: nil,
    queue: .main
) { [weak self, weak settingsStore] _ in
    _ = settingsStore  // ← toter Code
    Task { @MainActor in
        self?.settingsStore.refreshFoundationAvailability()
    }
}
```

Apple-API-Vertrag: `addObserver(forName:object:queue:using:)` returns `NSObjectProtocol`. Token muss zum `removeObserver(_:)`-Aufruf retained werden. AppDelegate-Lifecycle-Hooks: `applicationWillTerminate(_:)` existiert bereits (Zeile 186-191).

    didBecomeActiveObserver = NotificationCenter.default.addObserver(
        forName: NSApplication.didBecomeActiveNotification,
        object: nil,
        queue: .main
    ) { [weak self] _ in
        // Hop auf MainActor, weil refreshFoundationAvailability @Published-State
        // mutiert und SettingsStore non-Sendable ist (Swift-6 strict-concurrency).
        // Direkte Cross-Actor-Übergabe vom Notification-Closure in den Task
        // würde einen sending-data-races-Fehler erzeugen.
        Task { @MainActor in
            self?.settingsStore.refreshFoundationAvailability()
        }
    }
    ```

    nonisolated func applicationWillTerminate(_ notification: Notification) {
        MainActor.assumeIsolated {
            if let token = self.didBecomeActiveObserver {
                NotificationCenter.default.removeObserver(token)
                self.didBecomeActiveObserver = nil
            }
            self.hotkeyManager?.stop()
            self.cleanupTempFiles()
        }
    }
    ```
