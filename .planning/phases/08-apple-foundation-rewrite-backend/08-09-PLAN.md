# Plan 08-09: Apple-Foundation-spezifische Prompt-Varianten

## Objective

Plus-Modus macht zu viel Prosa, Rant-Modus gibt 1:1 zurück — weil die bestehenden Prompts für GPT-4o-mini geschrieben wurden und Apple Foundation sie anders interpretiert. Dieser Plan fügt Foundation-spezifische Prompt-Varianten ein ohne den OpenAI-Pfad zu verändern.

## Background

- **Plus-Problem:** Der OpenAI-Prompt sagt "professioneller Assistent für Textaufbereitung… liest wie eine geschriebene Nachricht" → Foundation interpretiert "professionell" als: Begrüßung, Einleitung, formelle Struktur hinzufügen.
- **Rant-Problem:** Foundation erkennt bei nicht-aggressivem Input nichts zu de-eskalieren und gibt den Text unverändert zurück — der `@Generable`-`neutralText` enthält dann das Original.
- **Hook:** `ModeProcessor.makeRewriteSystemPrompt(for:)` wird genau an der Stelle aufgerufen wo `backend` bereits bekannt ist (Zeile 205). Einfach backend-Parameter ergänzen und Foundation-Variante wählen.

**Schritt 2:** Im Body die Prompt-Auswahl backend-abhängig machen:

```swift
private func makeRewriteSystemPrompt(for mode: Mode, backend: RewriteBackend) -> String {
    var parts: [String] = []
    switch mode {
    case .blitztextPlus:
        let basePrompt: String
        if !settings.customPromptPlus.isEmpty {
            basePrompt = settings.customPromptPlus
        } else if backend == .appleFoundation {
            basePrompt = Mode.blitztextPlus.foundationRewritePrompt
        } else {
            basePrompt = Mode.blitztextPlus.defaultRewritePrompt
        }
        parts.append(basePrompt)
        parts.append(settings.styleForPlus.promptHint)
    case .blitztextRant:
        let basePrompt: String
        if !settings.customPromptRant.isEmpty {
            basePrompt = settings.customPromptRant
        } else if backend == .appleFoundation {
            basePrompt = Mode.blitztextRant.foundationRewritePrompt
        } else {
            basePrompt = Mode.blitztextRant.defaultRewritePrompt
        }
        parts.append(basePrompt)
    case .blitztext:
        break
    }
    if !settings.context.isEmpty {
        parts.append("Kontext der sprechenden Person: \(settings.context)")
    }
    if !settings.properNouns.isEmpty {
        parts.append("Schreibe folgende Eigennamen exakt richtig: " + settings.properNouns.joined(separator: ", ") + ".")
    }
    parts.append("Gib ausschließlich den umgeschriebenen Text zurück, keine Vorbemerkungen, keine Anführungszeichen.")
    return parts.joined(separator: "\n\n")
}
```

**Schritt 3:** Aufruf-Stelle aktualisieren (Zeile 205):

Custom-Prompt-Logik: wenn der User einen eigenen Prompt eingetragen hat, wird Foundation-Variant NICHT verwendet (User-Präferenz hat Priorität).
