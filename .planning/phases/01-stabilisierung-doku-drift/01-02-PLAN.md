In `BlitzText/Hotkeys/HotkeyManager.swift`:

1. Direkt nach den bestehenden privaten gespeicherten Properties (`private var lastTriggerAt: Date = .distantPast`, Zeile 22), aber außerhalb des `init`-Bereichs, ergänze einen MARK-Block mit den Konstanten:

```swift
// MARK: - Debounce

/// Mindestabstand zwischen zwei Hold-Mode-Übergängen.
/// 50 ms reicht, um CGEvent-Doppelfeuer beim Tasten-Loslassen zu schlucken,
/// ist aber kurz genug, dass man fn+Shift „antippen" kann, ohne die Aufnahme
/// zu verlieren. Quelle: empirisch ermittelt am M1, siehe ARCHITECTURE.md.
private static let holdDebounce: TimeInterval = 0.05

/// Mindestabstand zwischen zwei Toggle-Edges. 300 ms verhindert, dass ein
/// Doppeltipp ungewollt zweimal toggelt (start → stop sofort danach).
private static let toggleDebounce: TimeInterval = 0.30
```

Platzierung: vor `// MARK: - Detection` (also zwischen Zeile 79 `}` von `stop()` und Zeile 81 `// MARK: - Detection`). Falls dort kein expliziter MARK existiert, einfach vor `private func handleFlagsChanged` einfügen.

In `handleHoldTransition` (aktuell Zeile 111):
```swift

```
→

