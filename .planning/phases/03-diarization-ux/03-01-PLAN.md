## ADR: Variant A — Wrap FluidAudio.progressHandler statt eigenem Downloader

**Kontext:** CONTEXT.md D-06 sagte "eigener Downloader analog `LocalModelManager` + `ModelDownloader.swift`. Wir umgehen `DiarizerModels.downloadIfNeeded()` und ziehen die FluidAudio-Modelldateien selbst per URLSession."

**Befund (RESEARCH.md, Live-Inspektion FluidAudio 0.14.3):** FluidAudio expont bereits `DiarizerModels.downloadIfNeeded(to:configuration:progressHandler:)` mit `DownloadProgress.fractionCompleted ∈ [0, 1]` und `phase: DownloadPhase` (`.listing` / `.downloading(completedFiles, totalFiles)` / `.compiling(modelName)`). Source: `Sources/FluidAudio/Diarizer/Core/DiarizerModels.swift:92-98`, `DownloadUtils.swift:77-103`.

**Entscheidung:** Wir wrappen den FluidAudio-`progressHandler` (~80 LOC neuer Manager-Code) statt einen eigenen URLSessionDownload-Path zu reimplementieren.

**Begründung:**
1. **Code-Volumen:** ~80 LOC vs. ~200+ LOC (HF-Tree-Listing, Pattern-Filter, Partial-Cleanup, .mlmodelc-Bundle-Validation müssten alle reproduziert werden).
2. **Forward-Kompatibilität:** Bei FluidAudio-Updates (z.B. neues required Modell) ist Variant A automatisch korrekt. Variant B würde den File-Set bei jedem FluidAudio-Bump silent brechen.
3. **Pfad-Konsistenz:** FluidAudio's Default-Verzeichnis `~/Library/Application Support/FluidAudio/Models/speaker-diarization/` wird auch von `DiarizerManager.initialize` als Default gelesen. Eigenes Verzeichnis erzeugt Doppelkopien, wenn `directory:` nicht überall mitgegeben wird (RESEARCH.md "Pitfall 1").
4. **Cancel/Retry/Cache-Cleanup:** FluidAudio liefert `DownloadUtils.clearModelCache(forRepo:directory:)` für D-11 — Variant B müsste eigene Pfad-Konstanten pflegen.

**Trade-off (akzeptiert):** Pfad-Hardcoding an FluidAudios Default. Wenn Sandbox später aktiviert wird (Out-of-Scope dieser Milestone laut REQUIREMENTS.md), muss FluidAudio den Sandbox-Container respektieren — wäre dort genauso ein Thema wie für eigenen Downloader.

**Override-Pfad:** Falls der User Variant B will, kann er `/gsd-plan-phase 3 --research` mit explizitem D-06-Verweis erneut anstoßen. Diese Plan-Datei dokumentiert die research-grounded Abweichung; D-06 bleibt im Audit-Trail erhalten.

**Belassene D-06-Zusicherung:** "Volle Progress-Kontrolle" — Variant A erfüllt das via `progressHandler` exakt.

    Schritt 1 — `BlitzText/Transcription/ETAEstimator.swift` (NEU, ~50 LOC):

    Pure-Data, kein `@MainActor`, kein `ObservableObject`. Spec aus RESEARCH.md § ETA Strategy übernehmen — exakter Code:

    ```swift
    import Foundation

    /// Sliding-Window-ETA-Estimator über `DownloadProgress.fractionCompleted ∈ [0, 1]`.
    /// Pure data — kein MainActor, isoliert testbar. Rückgabe `nil` bedeutet
    /// "Geschwindigkeit wird ermittelt …" (UI-SPEC § Copywriting).
    struct ETAEstimator {
        private struct Sample {
            let time: Date
            let fraction: Double
        }

        private var samples: [Sample] = []
        private let windowSeconds: TimeInterval

        init(windowSeconds: TimeInterval = 5.0) {
            self.windowSeconds = windowSeconds
        }

        mutating func reset() {
            samples.removeAll()
        }

        /// Liefert geschätzte Restsekunden, oder `nil` wenn noch nicht genug Datenpunkte
        /// (Anlaufphase, oder Stagnation in der CoreML-Compile-Phase).
        mutating func tick(fraction: Double, now: Date = Date()) -> Double? {
            samples.append(.init(time: now, fraction: fraction))
            let cutoff = now.addingTimeInterval(-windowSeconds)
            samples.removeAll { $0.time < cutoff }

            guard let first = samples.first, samples.count >= 2 else {
                return nil
            }
            let elapsed = now.timeIntervalSince(first.time)
            let progressDelta = fraction - first.fraction
            guard elapsed > 0.5, progressDelta > 0.001 else { return nil }
            let rate = progressDelta / elapsed
            let remaining = max(0, 1.0 - fraction)
            return remaining / rate
        }
    }
    ```

    ```swift
    import Foundation
    import FluidAudio

    /// Test-Seam für DiarizerModelManager. Production-Default ist
    /// `FluidAudioDiarizerLoader`; Tests injizieren `FakeDiarizerLoader`.
    /// Pattern analog Phase-2-`RecorderProtocol` (DI-Seam ohne Netzwerk).
    protocol DiarizerLoaderProtocol: Sendable {
        /// Lädt das Diarizer-Modell, falls noch nicht vorhanden.
        /// `progressHandler` bekommt `fractionCompleted ∈ [0, 1]`.
        /// Wirft bei Netzwerk-/Speicher-/HF-Fehler — Klassifikation übernimmt der Manager.
        func downloadIfNeeded(
            progressHandler: (@Sendable (Double) -> Void)?
        ) async throws -> DiarizerModels

        /// Sync-Existenz-Check ohne Inferenz (Pre-Warm-Detection D-13).
        func isInstalled() -> Bool

        /// Cache-Cleanup vor Retry (D-11).
        func clearCache()
    }

    /// Production-Implementation. Konsumiert FluidAudio 0.14.3 direkt
    /// (Variant A — siehe ADR in 03-01-PLAN.md).
    struct FluidAudioDiarizerLoader: DiarizerLoaderProtocol {
        func downloadIfNeeded(
            progressHandler: (@Sendable (Double) -> Void)?
        ) async throws -> DiarizerModels {
            try await DiarizerModels.downloadIfNeeded(
                progressHandler: progressHandler.map { ph in
                    { (p: DownloadUtils.DownloadProgress) in ph(p.fractionCompleted) }
                }
            )
        }

        func isInstalled() -> Bool {
            // FluidAudio's Default-Pfad: ~/Library/Application Support/FluidAudio/Models/speaker-diarization/
            // Source: RESEARCH.md § FluidAudio Internals, On-Disk-Layout
            let support = FileManager.default
                .urls(for: .applicationSupportDirectory, in: .userDomainMask).first
            guard let support else { return false }
            let dir = support
                .appendingPathComponent("FluidAudio", isDirectory: true)
                .appendingPathComponent("Models", isDirectory: true)
                .appendingPathComponent("speaker-diarization", isDirectory: true)
            let seg = dir.appendingPathComponent(ModelNames.Diarizer.segmentationFile)
            let emb = dir.appendingPathComponent(ModelNames.Diarizer.embeddingFile)
            let fm = FileManager.default
            var isDir: ObjCBool = false
            return fm.fileExists(atPath: seg.path, isDirectory: &isDir) && isDir.boolValue
                && fm.fileExists(atPath: emb.path, isDirectory: &isDir) && isDir.boolValue
        }

        func clearCache() {
            let support = FileManager.default
                .urls(for: .applicationSupportDirectory, in: .userDomainMask).first
            guard let support else { return }
            let dir = support
                .appendingPathComponent("FluidAudio", isDirectory: true)
                .appendingPathComponent("Models", isDirectory: true)
            // FluidAudio's eigene Cleanup-API. Beim Aufruf: Repo-spezifisches Verzeichnis
            // wird gelöscht — nicht die ASR-Modelle daneben (die sind in eigenem Repo-Folder).
            DownloadUtils.clearModelCache(forRepo: .diarizer, directory: dir)
        }
    }
    ```

    Schritt 3 — `BlitzTextTests/Support/FakeDiarizerLoader.swift` (NEU, ~50 LOC):

    Test-Fake. `@unchecked Sendable` analog `FakeAudioRecorder` — Tests laufen alle auf `@MainActor`, kein Race möglich. `DiarizerModels`-Init ist internal (RESEARCH.md), daher Caveat: erfolgreicher Download im Fake würde keinen echten `DiarizerModels` zurückgeben können — Tests prüfen stattdessen state-Transitionen + lastError.

    ```swift
    import Foundation
    @testable import BlitzText
    @testable import FluidAudio

    /// Test-Fake für `DiarizerLoaderProtocol`. Konfigurierbarer Progress-Tick-Stream
    /// und optionaler injizierter Fehler. Wirft am Ende immer (auch bei "Erfolg"),
    /// weil `DiarizerModels` keinen public init hat — Tests prüfen state-Transitionen,
    /// nicht den `cachedModels`-Wert.
    final class FakeDiarizerLoader: DiarizerLoaderProtocol, @unchecked Sendable {
        var installed: Bool = false
        var failure: Error?
        var progressTicks: [Double] = []
        private(set) var downloadCallCount: Int = 0
        private(set) var clearCacheCallCount: Int = 0

        func isInstalled() -> Bool {
            installed
        }

        func clearCache() {
            clearCacheCallCount += 1
            installed = false
        }

        func downloadIfNeeded(
            progressHandler: (@Sendable (Double) -> Void)?
        ) async throws -> DiarizerModels {
            downloadCallCount += 1
            for tick in progressTicks {
                progressHandler?(tick)
                try await Task.sleep(nanoseconds: 5_000_000)  // 5 ms zwischen Ticks
            }
            if let failure {
                throw failure
            }
            // DiarizerModels-Init ist internal (siehe RESEARCH.md § FluidAudio Internals).
            // Tests prüfen state-Transitionen, nicht den cachedModels-Wert.
            // Bei "Erfolg" werfen wir einen Marker-Fehler, den der Manager als
            // Unbekannt klassifiziert. Test-Assertions arbeiten dagegen.
            throw NSError(
                domain: "FakeDiarizerLoader",
                code: 0,
                userInfo: [NSLocalizedDescriptionKey: "Test-Stub: kein echtes Modell"]
            )
        }
    }
    ```

    @testable import BlitzText
    import XCTest

    final class ETAEstimatorTests: XCTestCase {

        func testFirstTick_returnsNil_becauseNotEnoughSamples() {
            var est = ETAEstimator(windowSeconds: 5)
            let now = Date()
            XCTAssertNil(est.tick(fraction: 0.1, now: now))
        }

        func testTwoTicksWithinHalfSecond_returnsNil_becauseElapsedTooShort() {
            var est = ETAEstimator(windowSeconds: 5)
            let t0 = Date()
            _ = est.tick(fraction: 0.1, now: t0)
            // < 0.5 s elapsed
            XCTAssertNil(est.tick(fraction: 0.15, now: t0.addingTimeInterval(0.3)))
        }

        func testSteadyProgress_returnsExpectedSeconds() {
            var est = ETAEstimator(windowSeconds: 5)
            let t0 = Date()
            // 0.0 → 0.5 über 5 s → rate = 0.1/s, remaining = 0.5, eta ≈ 5.0
            _ = est.tick(fraction: 0.0, now: t0)
            _ = est.tick(fraction: 0.1, now: t0.addingTimeInterval(1))
            _ = est.tick(fraction: 0.2, now: t0.addingTimeInterval(2))
            _ = est.tick(fraction: 0.3, now: t0.addingTimeInterval(3))
            _ = est.tick(fraction: 0.4, now: t0.addingTimeInterval(4))
            let eta = est.tick(fraction: 0.5, now: t0.addingTimeInterval(5))
            XCTAssertNotNil(eta)
            XCTAssertEqual(eta!, 5.0, accuracy: 1.5,
                "Erwartet ~5 s Restzeit bei 0.1/s rate und 0.5 verbleibend")
        }

        func testReset_clearsSamples_nextTickReturnsNil() {
            var est = ETAEstimator(windowSeconds: 5)
            let t0 = Date()
            _ = est.tick(fraction: 0.1, now: t0)
            _ = est.tick(fraction: 0.2, now: t0.addingTimeInterval(1))
            est.reset()
            XCTAssertNil(est.tick(fraction: 0.3, now: t0.addingTimeInterval(2)))
        }

        func testStagnatedProgress_returnsNil_whenDeltaBelowThreshold() {
            var est = ETAEstimator(windowSeconds: 5)
            let t0 = Date()
            _ = est.tick(fraction: 0.5, now: t0)
            _ = est.tick(fraction: 0.5, now: t0.addingTimeInterval(1))
            // Compile-Phase-Stagnation: progressDelta = 0 < 0.001 → nil
            XCTAssertNil(est.tick(fraction: 0.5005, now: t0.addingTimeInterval(2)))
        }
    }

    import Foundation
    import Combine
    import FluidAudio

    /// State-Machine des Diarizer-Modell-Lifecycle.
    /// Spec: 03-CONTEXT.md D-15.
    enum DiarizerModelState: Equatable {
        case notInstalled
        case downloading(progress: Double, etaSeconds: Double?)
        case installed
        case failed(message: String)
    }

    /// `@MainActor`-Lifecycle-Manager für das FluidAudio-Diarizer-Modell.
    /// Wrapped `DiarizerModels.downloadIfNeeded(progressHandler:)` (Variant A —
    /// siehe ADR in 03-01-PLAN.md). Spec: 03-CONTEXT.md D-15, D-16.
    @MainActor
    final class DiarizerModelManager: ObservableObject {

        // MARK: - Published state for UI consumption

        @Published private(set) var state: DiarizerModelState = .notInstalled
        @Published private(set) var downloadProgress: Double?
        @Published private(set) var etaSeconds: Double?
        @Published private(set) var lastError: String?

        // MARK: - Dependencies (DI seam, Phase-2-Pattern)

        private let loader: DiarizerLoaderProtocol
        private var loadingTask: Task<Void, Never>?
        private var cachedModels: DiarizerModels?
        private var etaEstimator: ETAEstimator

        init(
            loader: DiarizerLoaderProtocol = FluidAudioDiarizerLoader(),
            etaWindowSeconds: TimeInterval = 5.0
        ) {
            self.loader = loader
            self.etaEstimator = ETAEstimator(windowSeconds: etaWindowSeconds)
            // Initialer State spiegelt Disk-Realität (D-13 Pre-Warm vorbereitend)
            if loader.isInstalled() {
                self.state = .installed
            }
        }

        // MARK: - Public API for UI + ParakeetClient

        /// Sync-Existenz-Check ohne Inferenz. Wird von `ParakeetClient.ensureLoaded`
        /// und `AppDelegate.bootstrap` (Pre-Warm) aufgerufen.
        var isInstalled: Bool { loader.isInstalled() }

        /// Cached `DiarizerModels`-Instanz für `ParakeetClient`-Konsum (D-16).
        /// `nil` wenn nicht installiert oder noch nicht geladen.
        var modelsIfInstalled: DiarizerModels? { cachedModels }

        /// Toggle-On-Trigger (D-01). Idempotent: zweiter Call während aktivem
        /// Download ist No-Op.
        func start() {
            // D-02: bereits installiert + im Cache → fertig, kein Download
            if loader.isInstalled(), cachedModels != nil {
                state = .installed
                return
            }
            guard loadingTask == nil else { return }
            beginDownload()
        }

        /// User-Klick auf "Erneut versuchen" (D-10, D-11).
        func retry() {
            // Pitfall 4 mitigation: alten Task canceln vor neuem Download
            loadingTask?.cancel()
            loadingTask = nil
            // D-11: partielle Dateien löschen vor Retry
            loader.clearCache()
            cachedModels = nil
            lastError = nil
            beginDownload()
        }

        /// Best-effort Pre-Warm beim App-Start (D-13, D-14).
        /// Wird von `AppDelegate.bootstrap` aufgerufen wenn `parakeetDiarization == true`.
        /// Fehler im Pre-Warm setzen `lastError`, aber App-Start blockiert nie.
        func prewarm() {
            // Wenn schon installiert + cached → nichts zu tun
            if loader.isInstalled(), cachedModels != nil {
                state = .installed
                return
            }
            // Sonst: regulärer Download-Pfad. Wenn Files schon da sind, ist das
            // ein No-Op-Download, der nur die MLModels in cachedModels lädt.
            // Wenn Files fehlen: echter Download mit Progress.
            guard loadingTask == nil else { return }
            beginDownload()
        }

        // MARK: - Private

        private func beginDownload() {
            etaEstimator.reset()
            state = .downloading(progress: 0, etaSeconds: nil)
            downloadProgress = 0
            etaSeconds = nil
            lastError = nil
            Log.write("DiarizerModelManager: Download gestartet")

            let task = Task { [weak self, loader] in
                do {
                    let models = try await loader.downloadIfNeeded(
                        progressHandler: { [weak self] fraction in
                            // Worker-Thread → MainActor (RESEARCH.md § Concurrency)
                            Task { @MainActor [weak self] in
                                self?.handleProgress(fraction: fraction)
                            }
                        }
                    )
                    await MainActor.run { [weak self] in
                        guard let self else { return }
                        self.cachedModels = models
                        self.state = .installed
                        self.downloadProgress = nil
                        self.etaSeconds = nil
                        self.loadingTask = nil
                        Log.write("DiarizerModelManager: bereit (Modell installiert)")
                    }
                } catch {
                    await MainActor.run { [weak self] in
                        guard let self else { return }
                        let msg = Self.classify(error)
                        self.lastError = msg
                        self.state = .failed(message: msg)
                        self.downloadProgress = nil
                        self.etaSeconds = nil
                        self.loadingTask = nil
                        Log.write("DiarizerModelManager: Download fehlgeschlagen — \(error.localizedDescription) → '\(msg)'")
                    }
                }
            }
            loadingTask = task
        }

        private func handleProgress(fraction: Double) {
            let now = Date()
            let eta = etaEstimator.tick(fraction: fraction, now: now)
            downloadProgress = fraction
            etaSeconds = eta
            state = .downloading(progress: fraction, etaSeconds: eta)
        }

        // MARK: - Error Classification (D-10, drei deutsche Klassen)
        // Strings sind LOCKED durch UI-SPEC § Copywriting Contract — bei Änderung
        // muss UI-SPEC zuerst geändert werden.

        static func classify(_ error: Error) -> String {
            // Klasse 1: Netzwerk
            if let urlError = error as? URLError {
                switch urlError.code {
                case .notConnectedToInternet,
                     .timedOut,
                     .cannotFindHost,
                     .cannotConnectToHost,
                     .networkConnectionLost,
                     .dnsLookupFailed,
                     .secureConnectionFailed,
                     .resourceUnavailable,
                     .internationalRoamingOff,
                     .callIsActive,
                     .dataNotAllowed:
                    return "Verbindung fehlgeschlagen. Prüfe deine Internetverbindung und versuch es erneut."
                default:
                    break
                }
            }
            // Klasse 2: Speicher
            let ns = error as NSError
            if ns.domain == NSCocoaErrorDomain
                && ns.code == CocoaError.Code.fileWriteOutOfSpace.rawValue {
                return "Nicht genug Speicherplatz für den Download (~80 MB werden gebraucht)."
            }
            if ns.domain == NSPOSIXErrorDomain
                && ns.code == Int(POSIXError.ENOSPC.rawValue) {
                return "Nicht genug Speicherplatz für den Download (~80 MB werden gebraucht)."
            }
            // FluidAudio-Errors → Netzwerk-Klasse (HF-Server-Probleme)
            if let hf = error as? DownloadUtils.HuggingFaceDownloadError {
                switch hf {
                case .rateLimited, .invalidResponse, .htmlErrorResponse, .downloadFailed:
                    return "Verbindung fehlgeschlagen. Prüfe deine Internetverbindung und versuch es erneut."
                case .modelNotFound:
                    return "Download fehlgeschlagen. Versuch es später erneut — wenn das Problem bleibt, schau in das Log unter ~/Library/Logs/BlitzText.log."
                }
            }
            // Klasse 3: Unbekannt (Default)
            return "Download fehlgeschlagen. Versuch es später erneut — wenn das Problem bleibt, schau in das Log unter ~/Library/Logs/BlitzText.log."
        }
    }
